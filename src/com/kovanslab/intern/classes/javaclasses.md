### Class

       -> A class is a Blueprint
       -> A class contains methods,fields,objects,Constructors...

       ex:
         Student application form template is a class
         our application that filled with our details is called objects

### Anatomy of classes

         -> Fields
         -> Methods
         -> Constructors

### Constructors

        -> Special method that runs when object is created.
        -> Same name as class
        -> No return type


### Types of Classes

        -> Normal class
        -> Abstract class
        -> final class
        -> static class

### Access Modifiers in Java

        -> public (Accessible from anywhere, Used for APIs, main methods, libraries)
        -> private (Accessible only inside the same class,Used for data hiding)
        -> protected (Same package → allowed )
        -> default (Accessible only inside same package)

### Static Block
        -> The Static Bock Run Once before the main method


### Instance Controlling
        -> controlling how many objects of a class can be created.
        -> Normally, Java allows unlimited objects
        -> Instance control says: “limit it”
