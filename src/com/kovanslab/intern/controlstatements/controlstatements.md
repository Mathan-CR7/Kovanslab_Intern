Control Statements

->They Decide
which code runs
how many times it runs
when it stops or skips

Types
1)Decision-Making
->if (Run code only if condition is true)
->if-else (if condition satisfies it will return true otherwise false)
->if-else-if (we can give more set of conditions)
->switch statement (it used of actions(printing,upgradeing))
->switch expression (It directly return value)

    2)Looping Statements
         ->for loop (Use For loop when we know the range or limit)
         ->while loop (Use when we dont know the range or limit)
         ->do-while loop (Runs at least once)
         ->for-each (We can Access the values directly)

    3)return
         ->Exit method
