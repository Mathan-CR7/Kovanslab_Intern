### Enums & Complex State

### enum
       -> The enum is short for enumeration
       -> Its a Special type used to define a fixed set of constants
       -> Fixed
       -> Type-safe

### Types of enum
       -> Enums with fields (You can attach data to each constant.)
       -> Enums with Constructors ()
       -> Enums with Abstract Method (Each constant defines its own behavior.)

### Complex state
       -> Have its own behavior
       -> Override methods differently
