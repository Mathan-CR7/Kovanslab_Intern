### Interface

      -> Before Java 8, interfaces could only have abstract methods (no bodies)
      -> Since Java 8, they can also include default and static methods (with implementation) and since Java 9, private methods are allowed.
      -> Object Creation is not allowed
      -> must use public keyword while implementing method
      -> Multiple Inheritance is done by Interface to avoid the Diamond problem

### Types of Interface

      ->  Normal Interface (More than one abstract method)
      -> Functional Interface (Only one abstract method ,It mostly used in lambda expressions)
      -> Marker Interface(interface that has no methods and no fields)
      -> Nested Interface (Interface inside the Interface or Class)
      -> Default and Static Methods 

### Abstract Class

      ->  An abstract class is declared using the abstract keyword
      ->  You can’t create objects , 
      ->  Can Have :
              1.abstract method
              2.normal method
              3.variables
              4.constructors

### Types of Abstract Classes

      -> Abstract Class with ONLY Abstract Methods
      -> Abstract Class with BOTH Abstract + Concrete Methods
      -> Abstract Class with NO Abstract Methods

### Lambda Expression
      -> Lambda Method is a short way to write a method
      -> Without Method name
      -> Without Return Type
